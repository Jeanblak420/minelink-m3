# 1. Main Goal of This System

You are adding a new top-level platform administration layer above all companies.

This account type is not part of a normal company. It is a **global platform owner/admin account** that can:

1. See every company using the app.
2. Group companies by organization type:

* `mineSupplier`
* `buyer`
* `transporter`

1. Open a company and see all users/employees under that company.
2. Group users by employee role:

* `management`
* `admin`
* `controllerWB`
* `security`
* `driver`

1. Generate unique serial keys/tokens for a company.
2. Set how many days the token is valid.
3. Set how many user seats the company is allowed to use.
4. Block or restrict company access when the token expires.
5. Allow a company to request more seats.
6. Create only one child super admin account.
7. Track every action done by the child super admin.
8. Allow the main super admin to download logs at any time.
