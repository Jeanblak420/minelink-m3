One-liner: Compact filter dropdown used in table/list toolbars.

```jsx
<Select label="All Clients" icon="person" options={['Atlas Buyer', 'Pioneer Mining']} />
<Select label="All Routes" icon="alt_route" options={routes} />
```

White pill with slate border and a chevron — matches the "All Clients ▾ / All Routes ▾" controls above active-trip tables. Options accept plain strings or {value,label}.
