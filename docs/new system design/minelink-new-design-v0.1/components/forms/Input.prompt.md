One-liner: Filled text field with label, optional leading icon, hint/error — the portal's standard form input.

```jsx
<Input label="Tons Loaded" required placeholder="e.g. 34.5" />
<Input label="Weighbridge / Ticket Number" placeholder="e.g. WB-0045" icon="confirmation_number" />
```

Slate-100 fill, transparent border that turns cyan on focus (red on error). Min 48px tall. Pair `required` with the asterisk shown in mockups.
