One-liner: The MineLink action button — cyan primary plus lifecycle-tinted confirm/depart variants used on dashboards, control panels and forms.

```jsx
<Button variant="primary" iconRight="arrow_forward">Open</Button>
<Button variant="go" icon="login" block>Mark Arrived</Button>
<Button variant="leave" icon="logout" block>Mark Left</Button>
<Button variant="outline" size="sm">Cancel</Button>
```

Variants: `primary` (cyan, default CTA), `go` (green — confirm load / mark arrived), `leave` (orange — mark departed), `tonal` (white pill on tinted cards), `outline`, `ghost`, `danger`. Sizes sm/md/lg; min height 48px at md for touch. Hover lifts 1px.
