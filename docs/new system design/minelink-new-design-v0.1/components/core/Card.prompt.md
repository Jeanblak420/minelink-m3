One-liner: The base surface for all portal content — rounded, softly shadowed, slate-bordered.

```jsx
<Card>…</Card>
<Card tone="hero">Overview tile with cyan wash</Card>
<Card tone="chrome">Navy promo panel</Card>
```

Tones: plain (white, default), hero (cyan gradient + accent border for headline overview tiles), inset (sunken well), chrome (navy gradient, white text). Radius is 20px (xl). Pass `onClick` to make it interactive.
